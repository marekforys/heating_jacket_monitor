## Overview

**moniheat me** is a Swift application designed to help individuals working or staying in cold environments manage their heating jackets efficiently. The app provides real-time temperature monitoring, control over jacket settings, and safety features to ensure optimal comfort and protection in harsh conditions.

## Features

- Real-time temperature monitoring of the heating jacket
- Remote control of jacket temperature and modes
- Safety shutoff and overheat alerts
- Historical temperature data logging
- Intuitive, user-friendly interface
